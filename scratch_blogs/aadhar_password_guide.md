## 1. Aadhaar Card PDF Password Format Kya Hai? (The Official Rule)

UIDAI dwara issue kiya gaya e-Aadhar Card ek default security password ke sath aata hai. Yeh password strictly **8 characters** ka hota hai aur iska standard format do cheezon ko mila kar banta hai:

1. **Aapke Name ke pehle 4 letters (CAPITAL Letters mein)**
2. **Aapka Birth Year (YYYY format mein)**

> [!NOTE]
> Agar aapke name mein spaces hain ya name 4 characters se chota hai, toh formatting thodi badal jati hai. Let's see all these scenarios in detail.

### Aadhaar Password Rules with Real-Life Examples:

| Full Name on Aadhaar | Year of Birth (DOB) | Aadhaar PDF Password | Scenario Explanation |
| :--- | :--- | :--- | :--- |
| **AMIT KUMAR** | 1989 | **AMIT1989** | Standard Name (> 4 letters) + YYYY |
| **RAVINDRA SHARMA** | 1974 | **RAVI1974** | First 4 characters of Name + YYYY |
| **P. KUMAR** | 1990 | **P.KU1990** | Special character/dot is counted as character |
| **DEV** | 2001 | **DEV2001** | Name length is 3 characters, so name + YYYY |
| **RIYA SEN** | 1995 | **RIYA1995** | Spaces in the first 4 characters are skipped |
| **ANIL** | 1985 | **ANIL1985** | Standard 4 letter name + YYYY |

### Common Mistakes to Avoid When Opening Aadhaar PDF:
* **Capital Letters Only:** Name ke pehle 4 characters hamesha **CAPITAL (UPPERCASE)** mein hone chahiye. Small letters (**amit1989**) kaam nahi karenge.
* **Do Not Use Full Date of Birth:** Password mein poori birthdate (DDMM) nahi aati, sirf **Birth Year (YYYY)** aata hai.
* **Special Characters & Spaces:** Agar aapka name **"S. KUMAR"** hai, toh password **"S.KU1992"** hoga, jisme dot (.) third character mana jayega.
